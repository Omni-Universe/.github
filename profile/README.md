# Omni Universe

Omni Terminal brings market data, research and trading workflows into one interface.

- [Omni Terminal](https://omniterminal.app/)
- [Omni Universe SDKs](https://github.com/InTheta/omni-universe-sdks) for market data and guarded trading agents
- [HL Vault SDK](https://github.com/InTheta/hl-vault-sdk) for Hyperliquid, HIP-3 and HIP-4 strategy vaults
- [Agent Capability Middleware](https://github.com/InTheta/agent-capability-middleware) for agent permissions and x402 policies
- [DefiLlama contribution](https://github.com/DefiLlama/dimension-adapters/pull/7627) for the Omni Terminal Hyperliquid builder adapter
